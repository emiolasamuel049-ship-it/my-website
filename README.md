# Visible Growth Studio

A responsive multipage static website built with HTML, CSS and JavaScript.

## Pages
- `index.html` — Home
- `services.html` — Services
- `portfolio.html` — Portfolio
- `about.html` — About
- `contact.html` — Contact

## Upload to GitHub
1. Create a new GitHub repository.
2. Upload every file and folder from this project.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

## Contact form
The contact page currently contains a placeholder Formspree endpoint:
`https://formspree.io/f/your-form-id`

Replace `your-form-id` with your real Formspree form ID, or replace the form action with another form provider.

## Custom domain
After GitHub Pages is enabled, you can connect a custom domain through **Settings → Pages → Custom domain**.

## Customization
- Replace project placeholder blocks in `portfolio.html` with real screenshots.
- Update the email address in `contact.html`.
- Change colors and typography at the top of `assets/style.css`.
- Add your logo or brand images to `assets/`.
